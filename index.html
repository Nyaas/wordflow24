Nguồn dữ liệu

Kéo thả một hoặc nhiều file .ics vào đây. Dữ liệu được xử lý ngay trong trình duyệt, không gửi đi đâu.

Cách lấy file từ Google Calendar
  1. Mở Google Calendar trên máy tính, bấm biểu tượng bánh răng, chọn Cài đặt.
  2. Chọn Nhập và xuất, rồi bấm Xuất.
  3. Giải nén file .zip tải về, mỗi lịch là một file .ics.
  4. Chọn các file .ics ở trên. Lịch lặp lại và sự kiện bị hủy được xử lý tự động.
